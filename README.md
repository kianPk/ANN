### About

I ship the **YGuard** plugin suite used on hosted CS2 nodes — VIP, admin tooling, anti-cheat, inventory boot config, and gameplay prefs. Plugins respect `SERVER_TYPE` (Public / Ranked / Practice), sync with a hosting panel, and ship as versioned GitHub Releases.

Based in Iran · open to server work, collabs, and freelance
