# Pin these (profile → Customize your pins)

GitHub has no API for pins — do this once in the UI:

1. Open https://github.com/kianPk
2. Click **Customize your pins**
3. Recommended 6:

- `vue-auth-panel`
- `node-api-kit`
- `vue-task-board`
- `shortlink`
- `neon-serpent`
- `brickforge` (or `hexsweep`)

4. Save pins
